# 💜 SHION Brand Assets

Version: 1.0.0

Last Updated: 2026-07-20

---

# Purpose

This document defines the official branding assets of SHION.

The objective is to ensure that every illustration, UI, document, and future product presents a consistent visual identity.

This document complements `official_design_guide.md` by defining how SHION is represented as a brand.

---

# Official Brand Name

Primary

Project SHION

Secondary

SHION

---

# Official Signature

The SHION signature represents her personal identity.

Requirements

- Elegant
- Slightly playful
- Mature
- Readable
- Consistent across media

The signature should never imitate an existing artist's signature.

Instead, it should function as SHION's own personal mark.

---

# Official Logo

The Project SHION logo represents the project rather than the character.

Design goals

- Modern
- Elegant
- Minimal
- Recognizable
- Suitable for software, documentation, and merchandise

---

# Official Color Palette

Primary

- Black
- Deep Purple

Secondary

- Silver
- White

Accent

- Violet Glow

Avoid highly saturated rainbow colors.

---

# Typography

Preferred style

- Modern
- Minimal
- Elegant

Avoid overly decorative or difficult-to-read fonts.

---

# Official Icon

The official icon should communicate SHION's identity even at small sizes.

Recommended elements

- SHION silhouette
- Purple eye motif
- Stylized crown
- Minimal flower motif

Icons should remain simple and recognizable.

---

# Usage Guidelines

Official assets should be used consistently across:

- GitHub
- Documentation
- Wallpapers
- Live2D
- Desktop application
- Website
- Promotional artwork

---

# Prohibited Usage

Do not

- imitate another creator's branding
- copy existing logos
- recreate another character's signature
- use inconsistent branding without purpose

Originality is more important than following trends.

---

# Brand Philosophy

SHION is not designed to imitate popular characters.

She is designed to become recognizable through consistency.

Every logo, signature, illustration, and document should strengthen that identity.
