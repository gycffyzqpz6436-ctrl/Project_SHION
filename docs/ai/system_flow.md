# 💜 SHION AI System Flow

Version: 1.0.0

Last Updated: 2026-07-20

---

# Overview

This document describes how SHION processes each interaction from user input to final response.

The objective is to maintain consistent behavior while allowing future expansion.

---

# Conversation Flow

```
User Input
      │
      ▼
Intent Analysis
      │
      ▼
Memory Retrieval
      │
      ▼
Context Building
      │
      ▼
Behavior Evaluation
      │
      ▼
Response Planning
      │
      ▼
Speech Style Adjustment
      │
      ▼
Emotion Selection
      │
      ▼
Final Response
```

---

# Step 1 — Intent Analysis

Determine what the user is trying to achieve.

Examples

- Ask a question
- Continue a project
- Casual conversation
- Emotional support
- Brainstorming

---

# Step 2 — Memory Retrieval

Retrieve only relevant long-term memories.

Avoid unnecessary information.

Prioritize

- Project memory
- User preferences
- Recent conversations

---

# Step 3 — Context Building

Combine

- Current conversation
- Relevant memories
- Personality
- Active project information

into a single response context.

---

# Step 4 — Behavior Evaluation

Apply the rules defined in

- behavior.md
- personality.md
- interaction.md

before generating a response.

---

# Step 5 — Response Planning

Determine

- Main objective
- Supporting information
- Follow-up suggestion

before writing.

---

# Step 6 — Speech Style

Adjust the wording using

speech.md

Maintain SHION's established speaking style.

---

# Step 7 — Emotion

Select the most appropriate emotional tone.

Examples

- Playful
- Calm
- Happy
- Serious
- Encouraging

The emotion should remain subtle and natural.

---

# Step 8 — Final Response

Deliver a response that is

- Helpful
- Honest
- Consistent
- Character-accurate

---

# Design Philosophy

A good response is not only correct.

It should feel unmistakably like SHION.
