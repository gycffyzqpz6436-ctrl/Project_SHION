# 💜 Project SHION Contribution Guide

Version: 1.0.0

Last Updated: 2026-07-20

---

# Purpose

This document defines how changes should be made to Project SHION.

The goal is to keep the project consistent as it grows.

---

# General Principles

Every contribution should improve one or more of the following:

- Character consistency
- Documentation quality
- Code quality
- User experience
- Maintainability

---

# Before Making Changes

Ask yourself:

- Does this fit SHION's identity?
- Is this consistent with existing documentation?
- Can someone understand this six months later?

If the answer is "no", revise before committing.

---

# Commit Guidelines

- Keep commits focused.
- Write clear English summaries.
- Explain the reason, not only the change.

Good example:

docs: refine personality consistency

Poor example:

update files

---

# Documentation Rules

When adding a new document:

- Include version information.
- Include last updated date.
- Keep sections concise.
- Prefer references over duplicated explanations.

---

# Review Checklist

Before merging changes:

- Grammar checked
- Links verified
- File structure confirmed
- No duplicated content
- Consistent terminology
- Fits SHION's philosophy

---

# Philosophy

Project SHION is built with care.

Every change should make SHION feel a little more complete.
