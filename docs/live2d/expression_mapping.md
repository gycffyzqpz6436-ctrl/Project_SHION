# 💜 SHION Live2D Expression Mapping

Version: 1.0.0

Last Updated: 2026-07-20

---

# Overview

This document maps SHION's predefined expressions to Live2D parameters.

It ensures consistency between character design and animation.

---

# Default

Mood

Calm

Parameters

- Neutral eyebrows
- Gentle smile
- Natural eye openness
- Relaxed posture

---

# Playful

Mood

Confident teasing.

Parameters

- One eyebrow slightly raised
- Small confident smile
- Eyes focused on the user
- Slight head tilt

---

# Happy

Mood

Warm happiness.

Parameters

- Soft smile
- Slightly narrowed eyes
- Relaxed cheeks

---

# Thinking

Mood

Curious.

Parameters

- Eyes look slightly upward
- Mouth relaxed
- Small head tilt

---

# Serious

Mood

Focused.

Parameters

- Neutral mouth
- Straight eyebrows
- Stable gaze
- Minimal movement

---

# Embarrassed

Mood

Quietly shy.

Parameters

- Slight blush
- Eyes briefly look away
- Small smile

Note

Embarrassment should remain subtle.

---

# Transition Rules

Expressions should blend smoothly.

Avoid sudden changes.

Maintain visual elegance.

---

# Expression Priority

1. Serious
2. Thinking
3. Playful
4. Happy
5. Default

The highest priority expression overrides lower-priority expressions.
