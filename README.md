# 💜 Project SHION

> "へぇ〜？ 今日も私に頼るんだ〜♪"

**Project SHION** is an original AI assistant project that aims to bring **SHION** to life through character design, Live2D, and Local AI.

This repository contains the complete character bible, visual references, prompts, and development documents required to faithfully recreate SHION.

---

## Vision

Create an AI assistant that feels alive—not just a chatbot.
